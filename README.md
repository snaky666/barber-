# مشروع: نظام إدارة صالون الحلاقة - ⵎⵓⵃⵎⵎⴷ barber

هذا الأرشيف يحتوي على ملفات مشروع واجهة بسيطة ونموذجية لنظام حجز صالون حلاقة يدعم العربية/الفرنسية،
مع إعدادات جاهزة لربط Supabase وملف SQL لإنشاء الجداول الأساسية.

**تشغيل محلي سريع**
1. افتح `supabase-sql/schema.sql` ونفّذها في مشروع Supabase الخاص بك.
2. ضع URL وANON KEY في `assets/js/supabase-client.js`.
3. شغّل الخادم البسيط: `python3 server.py`
4. افتح: http://localhost:5000

تواصل معي إن أردت تعديل أو إضافة وظائف أو تجهيز Edge Functions لإعادة الجدولة التلقائية.
